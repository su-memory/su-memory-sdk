# AI 代码质检清单（质检 Agent 逐项自查，输出问题清单+修复方案）

> 用法：对照本清单逐项检查改动，问题标记 `❌` 并给出修复方案；全部通过才可提交。

## A. 需求与范围
- [ ] 未擅自新增需求、扩展功能、改接口结构
- [ ] 未修改任务范围外的文件
- [ ] 与结构化需求/架构评审一致

## B. 代码规范
- [ ] 单一职责；单函数 ≤ 80 行；嵌套 ≤ 3 层
- [ ] 无魔法值（已抽常量/枚举）
- [ ] 命名规范（snake_case/camelCase/PascalCase，无拼音）
- [ ] 未跨层调用（路由不写业务、不直接写库）

## C. 安全
- [ ] 无裸 SQL 拼接（参数化/ORM）
- [ ] 无硬编码密钥/配置（走 .env）
- [ ] 无明文打印敏感字段（key/token/手机号/身份证）
- [ ] 写接口有鉴权；入参有校验

## D. 异常处理
- [ ] 无裸 except/catch、无吞异常
- [ ] 异常有处理路径（日志/重抛/降级）
- [ ] 未自创异常体系/返回格式

## E. 性能
- [ ] 无 N+1、无循环内查库/发 HTTP
- [ ] 列表分页；无全量返回

## F. 测试
- [ ] 新增逻辑有配套测试
- [ ] 覆盖正常/边界/异常/空值
- [ ] 测试已跑通全绿

## G. 提交规范
- [ ] diff ≤ 800 行
- [ ] `scripts/ai-verify/ai-guard.sh` 通过
- [ ] 无 TODO(待确认) 残留（如有须向人类说明）

## 质检结论
- 问题清单：
  1. ❌ [位置] 问题描述 → 修复方案
- [ ] 全部通过，可提交
